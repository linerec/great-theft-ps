    화면을 클릭하면 마우스가 잠깁니다 (Esc로 해제).

    걸을 때: W A S D 이동(스틱을 얼마나 밀었는지에 따라 걷기·조깅·달리기) · Shift 누르고 있기 스프린트(X 자동 연타) · X 천천히 걷기 · Space 점프(□) · 우클릭 조준(L2) · 좌클릭 사격(R2) · F 차량 탑승/하차(△, 그리고 차량 조작으로 전환)

    운전할 때: W 가속(R2) · S 브레이크/후진(L2) · A D 조향 · Space 핸드브레이크 · 마우스 시점. 차 근처(3.5m)에서 F.

    GTA V(PlayStation)에서 확인된 것: 스프린트=X 연타, 점프=□, 조준=L2, 탑승=△, 엄폐=R1, 차량 가속=R2. 그 외(브레이크 L2, 핸드브레이크 □, 모든 속도·카메라 수치, 시점 가속 공식)는 테스트베드의 가정이며 실제 게임과 다를 수 있습니다.

    화면을 클릭하면 마우스가 잠기고, 키보드와 마우스가 PS5로 전달됩니다 (Esc로 해제). 음성은 아직 나오지 않습니다.

    GTA 스타일 게임 내부 설정 (실제 게임에서는 알 수 없는 값)

    게임 내부 값을 바꾸면 매핑이 모르는 상태가 되어 회전 각도가 어긋납니다. 자동 보정은 게임을 스틱으로 직접 돌려 보며 측정해 표, 세로 비율, 데드존 모양, 조준 시 배율을 프로필에 채웁니다. 시점 가속은 시간에 따라 변해서 표로는 보정되지 않습니다(느린 움직임에서는 영향이 없고, 빠르게 오래 쓸어 넘기면 커집니다).

    설정

    프로필 (게임마다 따로 저장해 두고 골라 씁니다)

    키 배치

    패드의 버튼마다 어떤 키로 누를지 정합니다. + 키를 누른 뒤 쓰고 싶은 키나 마우스 버튼을 누르면 됩니다. 기본은 모두 누르는 동안(패드와 똑같이, 지연 없이)이고, 게임이 한 버튼의 짧게/길게를 다른 동작으로 쓸 때만 방식을 바꾸세요: 한 키는 짧게 한 번, 다른 키는 길게 유지. 한 키에 길게 누르면/두 번 누르면을 따로 두면 그 키의 일반 누름은 키를 뗄 때 나가서 조금 늦어집니다.

    누르는 시간 (위의 탭, 홀드, 길게/두 번 누르기에 쓰는 값)

    마우스 매핑

    마우스 느낌을 위해 게임 안의 설정도 맞추세요: 시점(카메라) 감도는 최대로, 데드존은 최소로, 가속이나 스무딩 옵션은 있으면 끄기. 그래야 마우스가 스틱으로 낼 수 있는 속도 범위가 넓어지고, 손의 움직임과 화면이 같은 비율로 움직입니다. 그 다음 아래 감도로 맞춥니다.

    프로필에 기록한 게임 내 설정 (내가 안다고 선언한 값)

    프로필 글 (전체 내용. 다른 사람과 주고받을 때 이 글을 복사합니다)

    등록한 콘솔

    이 컴퓨터에 저장돼 있습니다. 콘솔을 켜고 연결하는 데 쓰는 키는 화면으로 보내지 않습니다. 목록에서 지워도 PS5 쪽의 기기 목록은 그대로입니다.

      등록 정보는 컴퓨터의 ~/.gtp/consoles.json에 저장되어, 다시 등록하거나 PSN에 로그인할 일이 없습니다. 다른 컴퓨터로 옮기려면 npm run consoles 명령을 쓰세요.

      브리지

      보통은 바꿀 필요가 없습니다. 이 페이지를 연 브리지의 주소가 자동으로 들어 있습니다.

      진단

      셀프 테스트 열기 · 브라우저 안에서 매핑 엔진과 영상 재생기를 점검합니다.

      콘솔 등록

      처음 한 번만 합니다. 콘솔을 켜 두고, 설정 → 시스템 → 원격 플레이 → 기기 연결(PS5) 화면을 연 채로 거기 나온 8자리 코드를 입력하세요. 코드는 몇 분 안에 바뀝니다.

      PSN 계정 ID를 모르면 여기서 가져오기

      Sony 로그인 페이지에 직접 로그인한 뒤, 나온 주소의 일회용 코드로 계정 ID 숫자만 가져와 이 컴퓨터에 저장합니다. 이 방식은 Sony 공식 Remote Play 앱의 인증 정보(chiaki-ng 공개 소스의 값)로 코드를 교환합니다. 비공식 클라이언트가 그 정보를 쓰는 것이라 Sony 약관상 회색지대이니 본인 계정에만 쓰세요. 받은 접근 토큰은 저장하지도 기록하지도 않고 바로 버립니다. 주소의 code= 는 일회용 로그인 코드이므로 이 칸 밖에는 붙여 넣지 마세요.
