    Test game internal settings (values that cannot be known in a real game)

    GTA-style game internal settings (values that cannot be known in a real game)

    If you change the game's internal values, the mapping no longer knows them and the turn angle drifts. Auto-calibration turns the game with the stick by itself, measures it, and fills the table, vertical ratio, deadzone shape and aiming scale into the profile. Look acceleration changes over time, so a table cannot calibrate it (it has no effect on slow movement and grows with long, fast sweeps).

    Settings

    Language

    Kept in this browser. English is the default.

    Screen color

    Auto follows this device's setting. It is kept in this browser only.

    On start

    It wakes the PS5 and connects even from standby. Because of browser rules, sound only plays after you click the screen once. Applies on this device only.

    Controller

    No controller connected. Connect a controller (DualSense etc.) by USB or Bluetooth and press any button.

    Shortcuts

    Available on the PS5 screen while the mouse is not locked. (While it is locked, every key goes to the PS5. Press Esc to release it.)

    Use it like an app

    iPhone: Safari Share button → "Add to Home Screen". It opens full screen without an address bar. Android and Chrome on a computer: menu → "Install app" or "Add to Home screen".

    Profile (saved separately for each game; pick one to use)

    Key layout

    Choose which key presses each button of the pad. Press + Key, then press the key or mouse button you want. By default everything is while pressed (exactly like a pad, with no delay); change the mode only when a game uses a short press and a long press of one button for different actions: one key as short tap, another as long hold. If you give one key separate long press / double press actions, that key's plain press is sent when the key is released, so it comes a little later.

    Press timing (values used for the tap, hold, long press and double press above)

    Mouse mapping

    For a good mouse feel, set the in-game settings too: look (camera) sensitivity to maximum, deadzone to minimum, and turn off acceleration or smoothing options if there are any. That widens the speed range the mouse can produce through the stick, and your hand and the screen move in the same proportion. Then tune it with the sensitivity below.

    In-game settings recorded in the profile (values I declare that I know)

    Console game auto-calibration (measured from the PS5 video)

    Start the game on the PS5 and begin in a scene where the camera can turn freely (during play, not in a menu or cutscene, with the character standing still). It moves the right stick by itself, measures how far the picture turns, and fills in the "In-game settings" above and the response table. It takes about 40 seconds, and keyboard, mouse and touch input are ignored meanwhile. It is fine if the character moves or a car passes during a turn, but a plain background or a loading screen will not work.

      Register console
      
    
      You only do this once. Keep the console on, open the Settings → System → Remote Play → Link Device screen (PS5), and enter the 8-digit code shown there. The code changes within a few minutes.
      
    
      
    
    
    
    
      
      If you do not know your PSN account ID, get it here
      
      Log in on Sony's own login page, then use the one-time code in the address you land on to fetch the account ID number only and store it on this computer.
        This works by exchanging the code with the credentials of Sony's official Remote Play app (values from the public chiaki-ng source). An unofficial client using those credentials is a gray area under Sony's terms, so use it only with your own account.
        The access token you receive is neither stored nor logged; it is discarded at once. The code= in the address is a one-time login code, so do not paste it anywhere except this box.
